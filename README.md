# 简历JD匹配师

你的专属简历顾问。发给我一份JD，我帮你分析匹配度、找出优势和差距，然后自动生成一份针对性简历。支持中英双语，自带排版质检（页面溢出、孤立词检测），不用手动调格式。第一次用的时候把你的工作经历发给我就行，之后每次换JD都能一键出新简历。

## 我能帮你做什么

我不是一个简单的"帮你润色简历"的prompt。我是一套完整的简历生成工具链：AI分析 + Python脚本 + HTML模板 + 自动验证，端到端帮你搞定求职材料。

## 核心能力

### 1. JD匹配分析
发一份JD给我，我会对照你的工作经历给出匹配度评分（1-10分），列出你的优势、差距、以及如何用现有经历弥补差距的策略。

### 2. 定制简历生成
根据JD分析结果，自动生成一份针对性的简历HTML。公司名、时间线、联系方式这些关键信息由脚本从你的工作经历中精确提取，不会出错。AI只负责撰写"关于我"、技能列表和工作要点描述。

### 3. 自动排版验证
每次生成后自动检查：
- 页面是否超出A4尺寸
- 是否有孤立词（一个字单独占一行）
- 锁定的公司经历是否都出现了
- 个人简介是否包含具体数据指标

任何一项不通过都会自动修复并重新生成。

### 4. 求职信和邮件正文
同样的分析结果，一键生成配套的求职信和应聘邮件。

## 使用流程

**首次使用：**
1. 把你的工作经历发给我（文本即可）
2. 选择哪些经历必须出现在每份简历中
3. 告诉我你的个人链接（LinkedIn/GitHub等，可选）
4. 发一张照片（可选）

**日常使用：**
粘贴JD → 分析匹配度 → 生成简历 → 自动验证 → 拿走用

## 为什么不是纯prompt？

市面上大多数"AI改简历"就是一段prompt，让大模型直接输出文本。问题是：排版不可控、公司名可能拼错、格式每次都不一样。

我的方案是把AI擅长的（理解JD、撰写描述）和脚本擅长的（精确替换、排版验证、格式一致性）分开，各做各的。AI输出一个2KB的JSON配置，脚本负责把配置变成漂亮的HTML简历。

## 环境要求

- Python 3.8+
- [Playwright](https://playwright.dev/python/)（用于排版验证，可选但推荐）
  ```bash
  pip install playwright && playwright install chromium
  ```

## 文件结构

```
resume-generator/
  SKILL.md                          # Skill指令文件（Claude Code用）
  README.md                         # 本文件
  scripts/
    generate.py                     # 简历HTML生成器
    generate_cover_letter.py        # 求职信HTML生成器
    validate.py                     # A4溢出、孤立词、公司名校验
  assets/
    template-cn.html                # 中文简历模板
    template-en.html                # 英文简历模板
    template-cover-letter.html      # 求职信模板（中英双语）
    photo-base64.txt                # （用户提供）照片base64数据
  references/
    work-history.md                 # （用户提供）工作经历
    work-history-template.md        # 工作经历模板
```

## 更新日志

### v1.0.2 (2026-07-23)

**Bug修复：**

1. **照片渲染修复**：`inject_photo()` 现在自动检测图片格式（JPEG/PNG）并添加完整的 `data:image/{type};base64,` 前缀。之前注入的是裸base64数据，导致照片显示为空白。
2. **中文冒号支持**：Bullet加粗标签解析器同时支持英文冒号 `**Label**:` 和中文冒号 `**Label**：`。之前中文冒号会导致加粗格式不生效，直接以原始文本显示。
3. **未知配置字段警告**：生成时会检查config JSON中的字段名，拼错的字段（如 `"summary"` 而非 `"about_text"`）会打印警告，不再静默忽略。
4. **模板占位符残留检测**：验证器新增检查——如果输出HTML中仍残留模板占位符文本（如"职位1"、"技能1"），说明config缺少了对应字段，直接判定为FAIL。

### v1.0.1 (2026-07-22)

1. 修复中文简历"关于我"内容不生效的bug
2. 修复校验器误判about_text通过的bug（正则越界匹配到其他元素中的数字）
3. Playwright从可选改为必装，首次运行自动检测并提示安装命令

7. 每段工作经历要求3-5条bullet，不允许只写1-2条
8. core_competencies描述增加长度指引（中文15-25字/英文8-15词）
